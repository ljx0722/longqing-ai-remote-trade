# Navigation integration contract

Root owns sim.ts, main.ts, styles.css. Navigation implementer owns navigation.ts, renderer.ts and scene/ocean.ts.

Use real geographic degrees. Export GeoPoint { lon:number; lat:number }, NavigationState { position:GeoPoint; heading:number; manual:boolean; throttle:number; route:GeoPoint[]; leg:number; trail:GeoPoint[]; discovered:string[]; targetId:string|null; distanceSailed:number }, NavHazard { id:string; kind:'storm'|'pirate'|'fog'|'current'; lon:number; lat:number; radius:number; strength:number; label:string }.

Export createNavigation(port:Port,day:number):NavigationState, planSeaRoute(from:GeoPoint,to:Port):GeoPoint[], advanceNavigation(nav:NavigationState,distanceDegrees:number,day:number):{reached:boolean;blocked:boolean}, navigationHazards(day:number):NavHazard[], distanceDegrees(a:GeoPoint,b:GeoPoint):number, initializeNavigationGeography(geojson:unknown):void, portPoint(port:Port):GeoPoint, readNavigation(raw:unknown, fallbackPort:Port, unlockedPorts:Port[]):NavigationState|null. Fields may be extended but agree with root before changing names.

Root attaches navigation:NavigationState to GameState. Per-frame sim movement calls advanceNavigation, per-day economic tick handles wages/supplies/risk. Heading is radians clockwise from north. In manual mode movement uses heading and throttle; auto mode follows route. Sea routing must avoid major landmasses, with explicit river-port coastal access. No imaginary Suez/Panama canals in this timeline. Hazards deterministic by day, 32 max; trace limited ~500 points. Near-city manual dock radius 1.2 degrees (game-scale abstraction).

WorldRenderer keeps existing harbor API, adds setOceanView(enabled:boolean), isOceanView():boolean, updateNavigation(nav:NavigationState,availablePorts:Port[],hazards:NavHazard[]):void, setMapInteraction(onPort:(id:string)=>void,onPoint:(point:GeoPoint)=>void), getOceanMarkers():{id:string;name:string;x:number;y:number;visited:boolean}[], followShip():void. User must pan/zoom ocean, select city and water waypoint. Build a warm cartographic 2.5D world from public/data/land.geojson with relief land, deep blue/teal water, visible port settlements, discovery shading, animated ship, route and weather/pirate zones. Reference image priority is readable world coastline, exploration, dotted routes, discovered cities. Keep draw calls bounded and disposal correct. Root will call updateNavigation at most 10Hz and manage DOM labels/controls.
