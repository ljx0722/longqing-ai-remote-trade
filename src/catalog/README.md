# 商港与物产目录

当前世界目录包含 204 个历史商港 / 河港、202 座内陆城市，共 406 座城市，以及 1765 种有独立名称和价格的商品、344 条明确连接城市的陆路。其中保留最初的 39 个港口、29 个基础商品及其存档标识。商品细分涵盖具体材料、地方物产、加工形态和手工业制品；1765 是可交易品种数，并非 1765 种基础自然资源。

`ports.ts` 与 `major-ports.ts` 提供扩充港口，`goods.ts` 提供扩充物产，`markets.ts` 将物产分配至港口货架。内陆目录位于 `../inland-catalog.ts`，由 `../dominion.ts` 合并既有城市和陆路。内陆城市通过商队探索、购买和治理进入玩法，当前没有逐城独立的手动商品买卖货架。

## 地理与历史口径

- 坐标为接近历史港区的经纬度。`x = 经度 / 180`、`y = 纬度 / 90`，不能把归一化坐标直接当平面距离。乌尔、洛塔尔、米利都等地的古海岸与今日不同；扬州、诺夫哥罗德、阿瑜陀耶等为通海河运节点，航路需要表现河运与转运。
- 纪元是该商港加入玩家商网的窗口，不是建城年份。保存旧港口解锁顺序，例如里斯本、伦敦，并不表示这些城市此前不存在。城市用持续适用的地区描述代替固定朝代国号。
- 新增城市包含上海、香港、新安（深圳地区）、淡马锡（新加坡地区）、孟买、曼谷及更多中国、欧洲、南亚、中亚、非洲和美洲内陆节点。历史范围止于 1750 年，名单不代表今天世界所有主要城市；现代城市的同址历史节点也不等于当时已经存在今天的城市规模与名称。
- 城市抽屉支持古今城名及地区搜索，例如输入“纽约”可找到新阿姆斯特丹，输入“雅加达”可找到巴达维亚；显示名称仍采用历史目录口径。“已发现”与“本纪元地图”筛选区分可经营城市和待探索目标。本纪元未访问的内陆城以淡色地图标签显示并可定位，商队发现后才能购买。
- 物产依据公元前 3000 年至 1750 年间的历史材料、工艺、气候与商路常识编排。古代部分以尼罗河、两河、黎凡特、印度河贸易为基础；后续覆盖地中海、汉萨与波罗的海、印度洋季风、东亚海贸和近代早期跨大洋航路。
- 商品名含明确地理指向时，`markets.ts` 的来源规则将其绑定至相应地区出口港。港口的 `produces` 包括腹地供货与区域批发，并不声称矿山、茶园或工场就在码头上。进口货物进入 `demands`。
- 武夷岩茶、松萝炒青、德化白瓷、纹章瓷等晚于所属大类的样式单独设置较晚门槛；美洲跨洋节点从第 9 个纪元开放。纪元范围内部仍会简化几年的先后次序。
- 这是一份可玩的策划目录，尚非逐件具备考古出土记录、原始账单和精确生产年代的历史数据库。商品的细分名称是经营用规格；价格、标准箱量和需求强度是游戏数值。历史港口衰落、古河道、战争与区域生产链尚需专门内容考据。

进一步考据可沿《厄立特里亚海航行记》、印度洋贸易史、汉萨港市档案、唐宋市舶资料、明清外销瓷与早期航海贸易账簿核对。本轮没有将这些参考线索假称为已逐条核验的引文。

## 如何进入游戏

`goodsForPort(portId, eraIndex, sandbox)` 返回本地可采购货架，目前全时代货架为每港 28–58 种，平均约 30.2 种。六种启蒙物资帮助新玩家建立最初商路；其他货物按出产地、当地需求与同海域进口分配。全目录每个品种至少在一座港口实际供应，所有合格的本地产出和需求都会出现在本地货架。玩家携来的其他货物仍可卖出，相关行为由模拟层处理。

港口市场可以按分类、名称和持仓过滤，每页显示 12 项，并明确显示买入和卖出单价；完整货物图鉴也支持搜索和分页。顶部市场消息按商品家族关联具体的当地品种，最多提及三种货物。丰收、干旱仅影响当地出产；风暴、季风影响需要海运进口的货物，季风范围包括东南亚。消息只描述观察，不直接给出涨跌百分比或必赚指令。

港口和内陆城使用同一张连续 2.5D 世界地图。大陆海岸及主要岛屿来自 Natural Earth 1:110m 数据，另从同一来源的 1:50m 数据补入马耳他、罗得、马德拉、圣米格尔、冲绳、桑给巴尔、毛里求斯、留尼汪、济州 9 座岛屿。合并底图包含 136 个地理要素、5301 个坐标点，渲染与导航共用该数据。河流、森林和城镇建筑帮助地理辨识；陆路为经过筛选的游戏用连接，并非现实道路 GIS 网络。地图仍不能精确表达所有古海岸、小岛、街区与河道通航条件，海路规划另有陆地避让与指定河口引航路线。

`node work/catalog-check.mjs` 检查目录完整性、坐标范围、唯一名称、年代门槛、真实货架覆盖及旧存档标识；`node work/catalog-events-check.mjs` 检查全纪元消息与当地货架的对应、品种波动、来源地和晚期工艺门槛；`node work/dominion-check.mjs` 检查内陆城市、道路及城邦规则。`npm test` 执行包含这些项目与 `world-continuity-check.mjs` 的完整模拟层检查，本次已全部通过；其中连续世界检查为 21 组，包含 652 次实际买入再卖出无套利检验及 24 个新增港口的模拟实航检查。这些检查不代替历史逐项考据或真实设备性能验收。
